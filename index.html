System Help & User Documentation

Learn how to utilize the MUST AI Study Planner effectively.

How does the AI Scheduler work?

The system uses a multi-constraint heuristic algorithm. It assigns higher priority and more weekly study blocks to modules marked as Difficult or Critical, placing them early in your day when cognitive focus is highest.

How is my data stored?

All user data, modules, and timetable preferences are securely stored in your browser's Local Storage, isolated per registration account.

How to export schedules?

Navigate to the Interactive Timetable view and use the PDF or Excel export buttons to download offline copies for printing.

Role Permissions

Class Representatives, Lecturers, and Peer Tutors have authorization to post academic guidance notes visible to all enrolled students.
